## vCard

`buildVCard(profile)` returns vCard 3.0 text. Line order is fixed; every line ends with CRLF, including the last.
The exact output for the real profile (`␍␊` marks `\r\n`):

```
BEGIN:VCARD␍␊
VERSION:3.0␍␊
N:Herron;Michael;;;␍␊
FN:Michael Herron␍␊
TITLE:Systems & Process Engineer␍␊
EMAIL;TYPE=INTERNET:mherron734@gmail.com␍␊
URL:https://michael-herron.vercel.app␍␊
X-SOCIALPROFILE;TYPE=linkedin:https://www.linkedin.com/in/mherron734/␍␊
ADR;TYPE=WORK:;;;Durham;NC;;USA␍␊
END:VCARD␍␊
```

As a JS string: `['BEGIN:VCARD', …, 'END:VCARD'].join('\r\n') + '\r\n'`.

Rules:
- `escape(v)`: backslash first (`\` → `\\`), then `,` → `\,`, `;` → `\;`, and `\r\n` / `\r` / `\n` → `\n`
  (RFC 6350 § 3.4). Applied to text values: each `N` component, `FN`, `TITLE`, each `ADR` component. `EMAIL`, `URL`
  and `X-SOCIALPROFILE` are URI values and are written as-is.
- `N`: split `profile.name` at the **last space** (`' '`, not `\s`): family = after, given = before; no space →
  family = whole name, given empty. `N:<family>;<given>;;;`.
- `ADR`: split `profile.location` at the **last comma**: locality = before, region = after, both trimmed; no
  comma → locality = whole, region empty. Country is the constant `'USA'` in `vcard.ts` (Profile has no country,
  and adding one would change M0's `profile.test.ts` `toEqual`). `ADR;TYPE=WORK:;;;<locality>;<region>;;USA`.
- `TITLE` is `profile.positioning` (D1: a positioning line, not a job title). `&` needs no escaping.
- No `TEL` line, ever (D5). No `PHOTO` (keeps the file tiny; the headshot is on the page). No line folding needed:
  the longest line (X-SOCIALPROFILE) is 69 octets, under 75.
- Escaping fixture for the test: `{ ...profile, name: 'Ann;Marie,Jo\nSmith Doe', location: 'Back\\slash, NC' }`
  (TS source) must yield the lines (shown as they appear in the file):
  `N:Doe;Ann\;Marie\,Jo\nSmith;;;`, `FN:Ann\;Marie\,Jo\nSmith Doe`, `ADR;TYPE=WORK:;;;Back\\slash;NC;;USA`.
  **As TS string literals in the test** (each backslash doubled again):
  `'N:Doe;Ann\\;Marie\\,Jo\\nSmith;;;'`, `'FN:Ann\\;Marie\\,Jo\\nSmith Doe'`,
  `'ADR;TYPE=WORK:;;;Back\\\\slash;NC;;USA'`. Writing the file-form strings into TS would silently drop a
  backslash and test the wrong thing.

Route `src/app/michael-herron.vcf/route.ts` (a dotted folder name is a valid App Router segment):

```ts
import { buildVCard } from '@/lib/vcard';
import { profile } from '@/lib/data';

export const dynamic = 'force-static';

export function GET() {
  return new Response(buildVCard(profile), {
    headers: {
      'Content-Type': 'text/vcard; charset=utf-8',
      'Content-Disposition': 'inline; filename="michael-herron.vcf"',
    },
  });
}
```

Plain `Response` (not `NextResponse`) so the Jest node-environment test can call `GET()` directly. `inline` lets
iOS Safari show its "Add to Contacts" sheet instead of downloading.

## QR

- `npm i -D qrcode @types/qrcode` (spec ground rule 9 pre-approves both; checked: qrcode 1.5.4, @types/qrcode
  1.5.6). Nothing under `dependencies`. The lockfile change makes `.harness/init.sh` re-run `npm ci`
  (`package-lock.json -nt node_modules/.package-lock.json`).
- `package.json` scripts: `"qr": "node scripts/make-qr.mjs"`.
- `scripts/make-qr.mjs` imports the profile straight from TypeScript (D21):
  `import { profile } from '../src/lib/data/profile.ts';`. Node 24 strips the types (`profile.ts` has only an
  `interface` and a `const`, both erasable). Checked: it works and prints a harmless
  `MODULE_TYPELESS_PACKAGE_JSON` warning on stderr. **Do not** add `"type": "module"` to package.json to silence it
  (the warning is harmless and the change would reach every `.js` file the repo ever loads).
- Options, in one object shared by both outputs:
  `{ margin: 2, errorCorrectionLevel: 'M', color: { dark: '#0a0a0f', light: '#ffffff' } }`.
  URL: `` `${profile.siteUrl}/card?src=qr` `` = `https://michael-herron.vercel.app/card?src=qr` (D4).
- Outputs, paths resolved from `import.meta.url` so the script works from any cwd; `mkdir -p public/card` first:
  - `public/card/qr.svg` = `await QRCode.toString(url, { ...options, type: 'svg' })`, written **as returned**
    (it already ends with `\n`; add nothing, or the test's exact compare fails).
  - `public/card/qr.png` = `await QRCode.toFile(path, url, { ...options, type: 'png', width: 1024 })`.
- Checked in a scratch install: the code is 33 × 33 modules (37 with margin, `viewBox="0 0 37 37"`), the SVG is
  1986 bytes, the PNG is exactly 1024 × 1024 and 7.7 KB, two runs give byte-identical PNGs (so `npm run qr` twice
  leaves `git status` clean), and the SVG matches none of the content guard's patterns (the guard scans `.svg`).
- The script is run by hand; both outputs are committed. `qr.test.ts` keeps them honest.
